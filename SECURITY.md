# Security Policy

## Supported versions

The Dialogue Branch Platform is pre-1.0 (`0.x`). Only the **latest release** is
supported with security fixes; there are no maintained older branches. Fixes are
published in the next release rather than backported.

## Reporting a vulnerability

**Please do not report security vulnerabilities through public issues, pull
requests, or discussions.**

Report privately through GitHub's
[**Report a vulnerability**](https://github.com/dialoguebranch/platform/security/advisories/new)
form (repository **Security** tab → **Advisories** → *Report a vulnerability*).
This opens a private advisory visible only to you and the maintainers.

Please include, as far as you can:

- the affected component (`packages/core`, `apps/api`, `apps/bff`, `apps/studio`)
  and version or commit,
- a description of the vulnerability and its impact,
- steps to reproduce, and a proof of concept if you have one.

## What to expect

- We aim to acknowledge a report within a few working days.
- We will confirm the issue, keep you updated on progress, and let you know when
  a fix is released.
- We follow coordinated disclosure: please give us a reasonable window to
  release a fix before any public disclosure. We are happy to credit reporters
  who wish to be named.
